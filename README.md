IoT Health Monitoring System

Overview

This project presents an IoT-based health monitoring system designed to measure and monitor vital health parameters associated with COVID-19 symptoms. The system uses a NodeMCU microcontroller, an infrared temperature sensor, and a pulse oximeter sensor to collect health data and transmit it wirelessly to a mobile application for real-time monitoring.

----------------------------------------------------------------------------------------------------

Features

Real-time body temperature monitoring

Blood oxygen saturation (SpO₂) measurement

Heart rate monitoring

Wireless data transmission using Wi-Fi

Mobile application-based monitoring

Portable and low-cost IoT solution

Methodology

The system collects temperature, oxygen saturation, and heart-rate data through connected sensors. The NodeMCU processes the sensor readings and transmits the data to the Blynk mobile application using its built-in Wi-Fi capability. The application displays the collected information in a user-friendly format and can be used for remote health monitoring.

------------------------------------------------------------------------------------------------------------

Results

The developed system successfully monitored body temperature, blood oxygen saturation, and heart rate. Experimental results showed good agreement between the measured values and reference devices, demonstrating the reliability of the proposed IoT-based monitoring solution.
